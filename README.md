# キャラ対転記（Discord → Notion）

Discordの投稿を、Notionへ**5分ごと**に追記します
（このリポジトリが公開で、GASのタイマーを入れたとき。非公開だと30分ごと。理由は下の「無料枠」）。

- Discordの**カテゴリごと**に、Notionに同じ名前のギャラリーができる（「キャラ対」「メモなど」…。既定はすべてのカテゴリ）
- カテゴリの中の**チャンネルごと**に、そのギャラリーに同じ名前のページができ、投稿が末尾に追記される
- ピン留めした画像は、そのページのカバー（ギャラリーのサムネ）になる
- カテゴリに入っていないチャンネルは転記しない

GitHub Actions（GitHubが無料で定期実行してくれる仕組み）で動くので、PCを点けておく必要はありません。
転記の本体は `sync.gs`、それを動かす部品が `runner/`、進み具合が `state/state.json`、
5分ごとに起動の合図を送るGASのタイマーが `timer.gs` です。

> ★GAS（Google Apps Script）では動きません。GoogleのサーバーからDiscordへボットとして通信すると、
> Discordの入口で 403（internal network error）として止められるためです（2026年時点）。

## 最初の設定（10分）

GitHubの画面が日本語表示なら日本語の名前、英語表示ならカッコ内の英語の名前で探してください。

### 1. トークンを3つ入れる

1. このリポジトリの上のタブ「**設定**」（Settings）
2. 左のメニュー「**シークレットと変数**」（Secrets and variables）→「**Actions**」（アクション）
3. 「**新しいリポジトリシークレット**」（New repository secret）を押して、次の3つを1つずつ入れる。
   「名前」（Name）に左の名前を**大文字のまま正確に**、「シークレット」（Secret）に値を貼って
   「**シークレットを追加**」（Add secret）

   | 名前 | 値 |
   |---|---|
   | `DISCORD_BOT_TOKEN` | Discordのボットのトークン |
   | `NOTION_TOKEN` | NotionのコネクトのAPIトークン |
   | `NOTION_URL` | 転記先のNotionページ（またはギャラリー）のリンク |

   入れた値は二度と表示されません（GitHubが伏せて保管します）。間違えたら同じ名前で入れ直せば上書きされます。

### 2. 確認（checkSetup）を実行する

1. 上のタブ「**Actions**」（アクション）→ 左の「**キャラ対転記**」
2. 右の「**ワークフローの実行**」（Run workflow）▼ →「実行するもの」が `checkSetup` になっていることを確認 →
   緑の「**ワークフローの実行**」（Run workflow）
3. 数秒後に一覧に出る実行（黄色→緑か赤）を押す →「**run**」→「**実行**」の行を開くと、結果が読める
   - `★` の行が直すところ。全部まとめて出る
   - `★ボットがまだサーバーに入っていません` → 下に出るURLを開いて、サーバーを選んで「認証」
   - `★` が無くなると、「チャンネル → Notionページ」の対応と、サムネの見込みが出る
4. 直したら、もう一度 1〜3

### 3. 自動転記をオンにする

1. 「**設定**」（Settings）→「**シークレットと変数**」（Secrets and variables）→「**Actions**」→ 上の「**変数**」（Variables）タブ
2. 「**新しいリポジトリ変数**」（New repository variable）→ 名前（Name）に `SYNC_ENABLED`、値（Value）に `true` →
   「**変数を追加**」（Add variable）
3. 以後、自動で転記する（非公開のうちは30分ごと）。すぐ1回動かしたいときは、2 の手順で `sync` を選んで実行

**止めるとき**: `SYNC_ENABLED` を `false` に変える（進み具合は残るので、`true` に戻せば続きから）。

### 4. 5分ごとにする（リポジトリを公開にする）

1. 「**設定**」（Settings）→ 左のメニューの一番上「**全般**」（General）→ 一番下までスクロール
2. 赤い枠（Danger Zone）の「**Change visibility**」（公開範囲の変更）→「**Change to public**」（公開にする）
3. 確認のボタンが何回か出るので押し進める（パスワードや2段階認証を聞かれたら入れる）

ワークフローがリポジトリの公開・非公開を見て、公開なら5分ごとの枠も動かします（非公開に戻すと30分ごとだけに戻る）。
ただし **GitHub自身の定期実行は遅れたり飛ばされたりしやすく**、5分ごとにしても4時間半で2回しか動かなかったことがあります。
きっちり5分ごとにするには、次の 5 のタイマーを入れてください。

公開にすると誰でも見られるようになるのは、コード・実行の結果（チャンネル名と件数）・`state/state.json`（サーバー名とID）です。
**トークンは見えません**（シークレットは公開でも伏せたまま）。Discordの投稿の中身もここには出ません。
「ワークフローの実行」や設定の変更は、あなた（書き込みできる人）しかできません。

### 5. GASのタイマーで、きっちり5分ごとに起動する

Google Apps Script（GAS）の時間トリガーから、5分ごとにこのワークフローを起動します。
転記そのものはGitHub側で動くので、GASは「起動の合図」を送るだけです。

**(1) 起動の合図に使うトークンを作る**（このリポジトリのActionsを起動するだけの、権限を絞ったトークン）

1. https://github.com/settings/personal-access-tokens/new を開く
2. 「**Token name**」（名前）に `キャラ対タイマー`
3. 「**Expiration**」（有効期限）は選べる一番長いもの（「No expiration」（期限なし）があればそれ）
4. 「**Repository access**」（対象のリポジトリ）→「**Only select repositories**」（選んだリポジトリだけ）→ `kyaratai-sync` を選ぶ
5. 「**Permissions**」（権限）→「**Repository permissions**」の「**Actions**」を「**Read and write**」（読み書き）にする。ほかは触らない
   （「Add permissions」ボタンの画面なら、それを押して「Actions」を選び、「Read and write」に）
6. 一番下の「**Generate token**」（トークンを作る）→ 出てきた `github_pat_…` をコピー（画面を閉じると二度と出ない）

**(2) GASにタイマーを入れる**

1. https://script.new を開く（新しいGASのプロジェクトができる）→ 左上の「無題のプロジェクト」を `キャラ対タイマー` に変える
2. https://raw.githubusercontent.com/hagechanwww/kyaratai-sync/main/timer.gs を開いて全部コピーし、
   GASの「コード.gs」の中身を全部消して貼り付ける →「保存」（💾）
3. 左の歯車「**プロジェクトの設定**」→ 一番下の「**スクリプト プロパティを追加**」→
   プロパティ `GITHUB_TOKEN`、値に (1) のトークン →「**スクリプト プロパティを保存**」
4. 左の「**エディタ**」（`< >`）に戻る → 上の関数の選択で `startTimer` →「**実行**」
5. 「権限を確認」→ 自分のGoogleアカウント →「詳細」→「キャラ対タイマー（安全ではないページ）に移動」→「許可」
6. 下の「実行ログ」に「5分ごとのタイマーを入れて、1回目の合図を送りました」と出れば成功。
   このリポジトリの「Actions」に「キャラ対転記」の実行が増えていく

`★` が出たら、その文のとおりに直してもう一度 `startTimer`。

- **止めるとき**: 変数 `SYNC_ENABLED` を `false` にする（タイマーの合図は届くが、何もせずに終わる）。
  タイマーごと止めるなら、GASで `stopTimer` を実行
- **トークンの期限が切れると**: GASから「エラーのメール」が来て、転記は30分ごとの予備だけになる（GitHubからも期限の1週間前にメールが来る）。
  (1) でトークンを作り直し、(2)-3 で `GITHUB_TOKEN` の値を入れ替えるだけ（タイマーは入れ直さなくてよい）

## ふだんの使い方

- **サムネ**: チャンネルでサムネにしたい画像をピン留めする（最後にピン留めした画像がサムネ）。
  **ピン留めした投稿は本文には入らない**（転記した後でピン留めしても、次の回に本文から外れる。Notionで自分で書いたものは消さない）。
  本文にも残したいときは `sync.gs` の `CONFIG.SKIP_PINNED` を `false` に
- **投稿**: 5分ごと（GitHubの都合で少し遅れることがある）に、同じ名前のページの末尾へ追記される
- **サムネを選び直す**: ピン留めを外しただけでは変わらないので、「ワークフローの実行」で `rescanCovers` を選ぶ
- **新しいカテゴリ・チャンネル**: 作れば、次の回からNotionにギャラリー・ページが自動でできる（投稿があるものだけ）
- **転記したくないカテゴリ**（雑談・ルールなど）: `sync.gs` 上部の `CONFIG.EXCLUDE_CATEGORIES` に名前を書く（例: `['雑談', 'ルール']`）。
  チャンネル単位なら `CONFIG.EXCLUDE_CHANNELS`。すでにできたギャラリーはNotionで消してよい
- Discordでの編集・削除はNotionへ反映されない（追記だけ）
- 失敗が続くと、GitHubからメールが届く。実行の結果に `★` で原因が出る
- 実行の結果の最初の「設定の確認」に、自動転記がオンか・公開か・何で起動したかが出る

## 無料枠

公開リポジトリのGitHub Actionsは無料・無制限です。非公開だと月2,000分までで、
1回の実行は短くても1分と数えるため、5分ごと（月約9,000分）は入りきりません。30分ごと（月約1,500分）なら収まります。
そのため、ワークフローは**公開なら5分ごと、非公開なら30分ごと**に自動で切り替えます（GASのタイマーの合図も、非公開のときは何もせずに終わる）。
GAS側は1回の合図が1秒ほどなので、GASの無料の上限（トリガーの実行時間 1日90分）には十分収まります。

公開リポジトリは、60日間コミットが無いと定期実行がGitHubに止められます。
投稿が無い時期が続いても止まらないよう、45日コミットが無ければ `state/keepalive.txt` に日付を書いてコミットします。
